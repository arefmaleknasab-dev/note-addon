# یادداشت‌های بوم

افزونه یادداشت‌برداری بصری فارسی برای Chrome. برای نصب، پوشه را از مسیر `chrome://extensions` و با فعال‌کردن **Developer mode** به شکل **Load unpacked** انتخاب کنید.

برای ساخت فایل نصب/اشتراک‌گذاری: کل پوشه را zip کنید (فایل `manifest.json` باید در ریشه باشد). افزونه با `chrome.storage.local` ذخیره می‌شود و در تب جدید باز می‌شود. انتخاب متن در صفحات وب از منوی راست‌کلیک به یادداشت تبدیل می‌شود.
